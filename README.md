# Credit Card Fraud Analytics

## Project Overview
This project focuses on analyzing credit card transactions to identify fraudulent transaction patterns and evaluate fraud detection strategies using SQL.

## Business Objective
- Identify patterns in fraudulent transactions.
- Analyze transaction amounts and frequency.
- Understand fraud trends.
- Evaluate the effectiveness of proposed fraud detection rules.
- Develop data-driven recommendations to improve fraud monitoring.

## Technologies Used
- SQL
- Azure Databricks
- Apache Spark SQL
- Azure Data Lake Storage
- Delta Lake

## Dataset
Credit Card Fraud Detection dataset from Kaggle.

Dataset: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Project Tasks
1. Data Exploration
2. Fraud Trend Analysis
3. Transaction Behaviour Analysis
4. Fraud Detection Performance Metrics
5. Fraud Rule Testing
6. Business Recommendations
